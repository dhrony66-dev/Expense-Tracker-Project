# Expense Tracker Mini Project

A simple Python-based Expense Tracker for recording, viewing, and calculating daily expenses.

## Features

* Add expenses
* View all expenses
* Calculate total expenses
* Store data in `results.txt`
* Load previous expenses automatically
* Simple command-line interface

## Technologies

* Python
* File Handling
* Lists & Dictionaries
* Loops & Conditions
* Exception Handling

## How to Run

```bash
python "Expense Tracker Mini Project.py"
```

## Menu

```text
1. Add Expense
2. View All Expenses
3. View Total Expenses
4. Exit
```
